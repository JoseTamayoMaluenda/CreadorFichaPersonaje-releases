# Creador Ficha de Personaje

Crea fichas para fantasía, investigación, cyberpunk, ciencia ficción y cualquier otra temática. Juega partidas independientes y utiliza dados 3D.

## Descargar

[Descargar la última versión para Android](https://github.com/JoseTamayoMaluenda/CreadorFichaPersonaje-releases/releases/latest)

Compatible con Android 9 o posterior. Descarga el archivo APK e instálalo. Android puede pedir permiso para instalar desde el navegador o desde la app.

## Actualizaciones

La app consulta si hay versiones nuevas en segundo plano. Cuando haya una, podrás descargarla o dejarla para más tarde. Para actualizar, instala la nueva versión encima de la anterior: tus fichas creadas, fichas descargadas y partidas se conservarán. No desinstales la app ni borres sus datos.

Puedes crear, editar, jugar y descargar fichas sin registrarte. Solo necesitas una cuenta para subir tus fichas a la comunidad.

Este repositorio contiene únicamente las versiones públicas, sus archivos de comprobación y la información para actualizar. El código fuente está en un repositorio privado.
